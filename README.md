## Miről szól?
Ez teljesen hardveralapú VGA időzítőjelgenerátor. A célja a leírásban olvasható. Ez a repo a projekt KiCad nyák fájljait, a kapcsolási rajz szkennelt változatát, illetve a közeljövőben a dokumentációt is tartalmazni fogja. Egy már létezik [Bloggeren](https://magyarglobus.blogspot.com/p/haladas.html), viszont tervben van azt a nyilvánosság elől elzárni (továbbra is elérhető lesz, de csak linkekkel).
Én magam számos más elektromos eszközhöz használnám, mint például egy házilag eszkábált videojáték-konzolhoz, amit már 2021. novembere óta meg akarok csinálni.
Az eredeti blog [itt](https://magyarglobus.blogspot.com/2026/10/elkoltozott.html) leledzik, csak archív célokat szolgál. Ott vannak helyzetjelentések 2026. október 4. előttről.
